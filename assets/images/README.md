# Source images

Put original photos and screenshots here (JPG or PNG), then run:

```bash
npm run images
```

This writes `public/images/<name>.avif` and `public/images/<name>.webp` (max 1600 px wide) and prints the width and height to put into the content file, so the page reserves the right space and nothing jumps while loading.
