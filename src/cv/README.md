# CV PDFs

Put the two PDF files here, with exactly these names:

- `Tomas_Vlasak_CV_EN.pdf`
- `Tomas_Vlasak_CV_CS.pdf`

The build copies them to `/cv/Tomas_Vlasak_CV_EN.pdf` and `/cv/Tomas_Vlasak_CV_CS.pdf`, where the download buttons on the CV page point. If a file is missing, the build still passes and only prints a warning.

The paths are set in `pdf` in `cv.json`.
